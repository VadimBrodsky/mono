Data Types in C

- `void` empty type
- `char` single character / byte
- `int` integer
- `long` integer that can hold larger values
- `float` decimal numbers
- `double` decimal number with more precision

```c
int count = 10;
char last_initial = 'H';
int age = 23;
long age_of_universe = 137980000000;
float liters_per_pint = 0.568f;
double speed_of_swallow = 0.01072896;
```
