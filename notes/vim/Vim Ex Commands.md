`<C-d>` to show all options in an ex command, ex: `colorscheme<C-d>`

## Explore
- `:Ex` - explore, replaces the current buffer with the file browser
- `:Vex` - vertical explore, same as :Ex but in a vertical split
- `:Sex` - split explore, same as :Ex but in a horizontal split
- `:reg` to show the registers
