The [`love.graphics.setFont`](https://love2d.org/wiki/love.graphics.setFont) function sets Love2D's currently active font (of which there can be only one active at a time) to a passed-in font object that we can create using [[./love.graphics.newFont]].

```lua
love.graphics.setFont( font )
```
