## Strings
Strings in Python are immutable and iterable
### Substring Access
Using array syntax
```python
course = “Programming Python”
course[0]     # P
course[-2]    # n
course[0:3]   # Pyt
course[:3]    # Pyt
course[0:]    # Python Programming
course[:]     # Python Programming
```
### Formatted Strings
```python
first = “John”
last = “Snow”
full = f”{first} {last}”
```
