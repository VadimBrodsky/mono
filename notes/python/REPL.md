##  REPL

Start the REPL by running `python3`

REPL methods
- `type()` - prints the type of the passed object
- `dir()` - prints the directory of methods available on a passed object
- `help()` - prints documentation about a method or object
- `id()` -  returns the identity of an object, memory location
- `len()` - returns the number of items in a container
