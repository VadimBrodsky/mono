# Create and Validate

Given a SlopLang language feature, complete these skills in order:

1. Load and follow the `create-test-program` skill for the requested feature. Complete its workflow and resolve any issues it identifies before proceeding.
2. Load and follow the `validate` skill to run the full project validation suite.

Do not duplicate the workflows or validation commands from those skills here; they are the source of truth. Report the created paths and the results of both skills, including any failures.
