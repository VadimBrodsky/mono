The `help` command list all of the basic commands of the Pico-8 terminal:

* `load` - opens a .p8 file from the currently open folder 
* `save` - saves the currently loaded game in a .p8 game file in the currently opened folder
* `run` - starts the currently loaded game
* `resume` - continues the currently loaded game where last exited
* `shutdown` - fully closes pico-8
* `reboot` - fully restarts pico-8
* `install_demos` - downloads a handful of demo games to play and learn from
* `ls`- "list" the files and folders in the currently opened folder
* `cd` - "change directory" opens a specific folder in the currently opened folder
* `mkdir` - "make directory" creates a new folder in the currently opened folder
* `keyconfig` - "key configuration" opens menu for changing the player controls on the keyboard
* `splore` - "explore" opens menu for browsing and downloading free games shared by the community
* `folder` - opens the working directory in the OS file explorer
