# Declaring Variables
- Go is a statically typed language.
- Statically typed means that each statement in the program is checked at compile time.
- It also means that the data type is bound to the variable, whereas in Dynamically linked languages, the data type is bound to the value.

```golang
var i int      // long variable declaration, without initialization
i := 1         // short varialbe declaration, used with initialization
i := int64(1)  // short variable declaration, with type conversion
```
