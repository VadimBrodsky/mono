Lua uses loose, implicit types. A variable can have any type, once a variable is assigned a type, it can be assigned any other type.

## Creating Variables

```lua
foo = "bar"
```

## Assigning variables

The `=` operator is used to assign values to variables

```lua
color = "red"
color = "green"
color = "blue"
```
