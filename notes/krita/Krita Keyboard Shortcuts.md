- `m` to mirror the canvas
- `6` - rotate clockwise
- `4` - rotate counterclockwise 
- `5` - reset rotation
- `+` - zoom in
- `-` - zoom out
- `1` - reset the zoom to 100%
- `2` - reset zoom to fit canvas
- `3` - reset zoom to canvas width 
- `[` - size down the brush
- `]` - size up the brush
- `Shift + drag` - resize brush
- `Cmd + Click` - 	colour pick
- `Shift + Space + Drag` - rotate canvas
