- Elm uses the standard mathematic operators for numerics: `+`, `-`, `*`, `/`, `^`, `//`
- The `+` operator is for addition, it can only be used on numbers.
- Use [[Operators]] to create expressions with numbers.
```elm
pi                           -- 3.141592653589793 : Float
123 + 123                    -- 246 : number
1 / 2                        -- 0.5 : Float
2 ^ 11                       -- 2048 : number
48 // 10                     -- 4 : Int
12345 - (5919 * -15)         -- 101130 : number
```
