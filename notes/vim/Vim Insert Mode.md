In insert mode the keyboard functions regularly, inserting text into the buffer.


## Entering Insert Mode

- `i` for insert, marks the current place as the insertion point


## Exiting Insert Mode

- `Esc` key, moves the cursor back one space and returns back to [[./Vim Command Mode|command mode]]
