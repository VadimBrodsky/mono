Press `Esc` to toggle between the terminal and the editor.

## Font
- Pico-8 uses a pixel based font in which all characters are lowercased. Uppercase letter print symbols to the screen.
- For example `shift+h` draws a heart.

## Keyboard shortcuts
- `Ctrl + e` - jump to end of line
- `Ctrl + w` - jump to beginning of the line
- `Ctrl + b` - comment / uncomment a block
