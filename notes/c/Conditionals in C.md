# Conditionals in C
Use the `if` statement to perform a conditional operation.

Can test for multiple conditions using [logical operators](Logical operators in C). Any value that
is not `0` will evaluate to `true`.

```c
if (x > 10 && x < 100) {
  puts("x is greater than 10 and less than 100!");
} else {
  puts("x is less than 11 or greater than 991");
}
```
